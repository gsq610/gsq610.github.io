# Si Qi Goh — Personal Research Website

Interactive, framework-free academic portfolio built for GitHub Pages.

## Deploy at `https://gsq610.github.io`

1. Create a public GitHub repository named `gsq610.github.io`.
2. Upload all files in this folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)` if GitHub Pages is not enabled automatically.

## Main interactions

- Research theme orbit and synchronized research focus panel
- Three animated primary tabs: Research, Experience, Engagements
- Publication search, category filters, and detail dialog
- Expandable professional timeline
- Engagement filters
- Light/dark theme
- Scroll progress, reveal animations, pointer spotlight, and subtle card tilt
- Responsive mobile layout and reduced-motion accessibility

## Files

- `index.html` — content and semantic structure
- `style.css` — complete visual design and responsive layout
- `script.js` — interactions
- `assets/favicon.svg` — favicon

No package installation or build step is required.
